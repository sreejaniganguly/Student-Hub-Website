#  Student Hub Website

**CodeNest** is a beginner-friendly educational website built using **HTML** and **CSS**. It provides students with a clean and modern interface to explore learning resources, create an account, and navigate through different sections of the website.

##Website Preview
[!image](https://github.com/sreejaniganguly/Student-Hub-Website/blob/5af46c94359c2fc42a8f9f7d2714ae36aff4038a/screenshot1.png)

##  Features

-  Home page
-  Modern Sign Up page
-  Videos page
-  Responsive navigation bar
-  Student registration form
-  Clean and minimal UI
-  Beginner-friendly website structure

##  Technologies Used

- HTML
- CSS

##  Learning Objectives

This project helped me practice and strengthened my HTML & CSS concepts.
